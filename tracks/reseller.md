# HCPN Indonesia — Reseller Track

> **Track Focus:** Product Knowledge, Sales Enablement, Solution Selling, and Partner Activation  
> **6-Month Outcome:** **Sales Ready**  
> **12-Month Outcome:** **Industry-Aware, Pipeline-Generating, Customer-Activating Reseller**

---

## 1. Track Purpose

The Reseller Track is designed to develop Huawei Cloud reseller capability from basic product understanding into measurable sales activation.

The intended progression is:

**Product Knowledge → Solution Understanding → Sales Capability → Commercial Readiness → Partner Activation → Customer Acquisition**

This track should not be treated as a sequence of training events only. Every month must produce an observable capability, assignment, or business output.

## 3. Entry Requirements

No advanced technical background is required.

Recommended minimum readiness:

- understanding of basic cloud concepts;
- familiarity with customer sales processes;
- basic awareness of enterprise IT solutions;
- registered participation in the HCPN partner enablement program.

Optional pre-assessment:

- cloud fundamentals quiz;
- product awareness survey;
- sales maturity assessment;
- current pipeline / customer-segment mapping.

---

## 4. 6-Month Capability Objective

By the end of Month 6, a reseller should be able to:

1. explain Huawei Cloud value propositions;
2. identify relevant Huawei Cloud services for common customer needs;
3. conduct basic customer discovery;
4. map customer pain points to cloud solutions;
5. position Huawei Cloud against customer requirements;
6. build a basic solution and commercial proposal;
7. understand HCPN-related partner processes;
8. register or progress qualified sales opportunities;
9. present a customer-facing solution pitch;
10. pass the Reseller Sales Readiness Assessment.

## 5. Month 1 — Huawei Cloud Product Quick Start

### Theme

**Foundation**

### Objective

Build basic understanding of Huawei Cloud, its core service categories, and its value proposition for customers.

### Core Topics

- Huawei Cloud overview
- Cloud service models
- Compute services
- Storage services
- Networking
- Database
- Security
- Backup and Disaster Recovery
- Cloud Native overview
- AI and Data overview
- Typical enterprise use cases
- Huawei Cloud ecosystem overview
- HCPN introduction

### Learning Outcomes

Participants should be able to:

- explain what Huawei Cloud provides;
- identify major Huawei Cloud service categories;
- explain common cloud business drivers;
- identify at least three customer use cases;
- explain the basic role of an HCPN reseller.

### Recommended Delivery

| Activity | Duration |
|---|---:|
| Instructor-Led Training | 3 hours |
| Product Demo | 1 hour |
| Self Learning | 2 hours |
| Assessment | 30 minutes |

### Practical Assignment

Create a **Huawei Cloud Product Mapping Sheet**.

| Customer Requirement | Huawei Cloud Capability |
|---|---|
| Virtual Server | Compute |
| Application Storage | Object / Block Storage |
| Secure Network | VPC / Security Services |
| Managed Database | Cloud Database |
| Backup | Backup / DR Services |

### Evidence

Partner may submit:

- assessment result;
- completed product mapping sheet;
- public-safe workshop summary.

### Completion Gate

- [ ] training completed;
- [ ] assessment completed;
- [ ] product mapping assignment submitted;
- [ ] minimum capability score achieved.

## 6. Month 2 — HCCDA-Tech Essentials / Technical Essentials for Sales

### Theme

**Knowledge**

### Objective

Enable reseller sales personnel to understand enough technical concepts to conduct credible customer conversations.

### Core Topics

- Cloud architecture fundamentals
- Availability Zones and Regions
- Elasticity and scalability
- Compute sizing concepts
- Storage types
- VPC and subnet concepts
- Load balancing
- Security basics
- IAM fundamentals
- Database fundamentals
- Backup concepts
- Monitoring basics
- High availability
- Basic cost considerations

### Learning Outcomes

Participants should be able to:

- understand common technical terminology;
- communicate with customer IT teams;
- understand simple cloud architecture diagrams;
- differentiate major infrastructure components;
- identify when a pre-sales specialist is required.

### Recommended Delivery

| Activity | Duration |
|---|---:|
| Technical Essentials Class | 4 hours |
| Architecture Walkthrough | 2 hours |
| Self Learning | 2 hours |
| Quiz | 30 minutes |

### Practical Assignment

Analyze a simple customer scenario:

> A customer runs one web application, one database, and one file storage server on-premises and wants to move to cloud.

Create a simple mapping for:

- compute;
- network;
- storage;
- database;
- security;
- backup.

### Capability Gate

- [ ] technical fundamentals completed;
- [ ] architecture exercise submitted;
- [ ] knowledge assessment completed;
- [ ] reseller can explain the proposed architecture at a high level.

## 10. Month 6 — Reseller Sales Readiness Assessment

### Theme

**Validation**

### Objective

Validate that the reseller can independently conduct a basic Huawei Cloud sales cycle.

### Assessment Components

| Assessment | Weight |
|---|---:|
| Product Knowledge | 20% |
| Technical Fundamentals | 15% |
| Discovery Skills | 20% |
| Solution Mapping | 15% |
| Customer Proposal | 15% |
| Sales Pitch | 15% |
| **Total** | **100%** |

### Final Simulation

The reseller must:

1. conduct customer discovery;
2. identify business requirements;
3. identify technical requirements;
4. recommend a solution direction;
5. explain business value;
6. present a customer proposal;
7. define next steps.

### Suggested Readiness Levels

| Score | Status |
|---|---|
| < 50 | Foundation |
| 50–69 | Developing |
| 70–84 | Sales Ready |
| 85–100 | Advanced Sales Ready |

> These thresholds are proposed program-management values and are not official Huawei Cloud certification or HCPN qualification thresholds.

### Month 6 Exit Criteria

- [ ] mandatory modules completed;
- [ ] Month 1–5 assignments completed;
- [ ] final assessment completed;
- [ ] customer pitch delivered;
- [ ] readiness score meets the program target;
- [ ] next 90-day business activation plan exists.

## 11. Monthly Delivery Model

Each month follows the same enablement cycle:

**Week 1 — Learn**  
Instructor-led session or online learning.

**Week 2 — Practice**  
Workshop, demo, role-play, or scenario exercise.

**Week 3 — Apply**  
Partner assignment or customer-related activity.

**Week 4 — Validate**  
Assessment, review, or capability validation.

Operating model:

**Learn → Practice → Apply → Validate**

## 16. Months 7–12 Extension

The second half should not repeat basic sales enablement.

The focus changes to:

**Sales Ready → Industry-Aware → Solution-Specialized → Pipeline-Generating**

| Month | Theme | Focus | Expected Output |
|---|---|---|---|
| M7 | Advanced Product Update | New / advanced services | Updated solution knowledge |
| M8 | Industry Solution Selling | Industry-specific customer needs | Vertical pitch |
| M9 | Advanced Discovery | Complex customer requirements | Account opportunity map |
| M10 | Customer Workshop | Real customer engagement | Workshop / discovery output |
| M11 | PoC & GTM | Joint customer activation | PoC / campaign candidate |
| M12 | Annual Business Review | Capability + business review | Next-year partner plan |

## 19. Definition of Success

The Reseller Track should not be reported only as:

> "50 people attended reseller training."

A stronger management report is:

```text
50 participants trained
        ↓
45 completed
        ↓
38 passed assessment
        ↓
30 sales-ready personnel
        ↓
20 active account plans
        ↓
12 qualified opportunities
        ↓
5 customer workshops / PoCs
        ↓
business outcome
```

This creates a measurable connection between partner training and partner business activation.
