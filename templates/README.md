# HCPN Indonesia — Partner Enablement Templates

This directory contains reusable templates for operating the partner enablement program consistently across Reseller, Distributor, Service Partner, and CSP tracks.

---

## Template Catalog

| Template | Purpose | Recommended Use |
|---|---|---|
| [Partner Onboarding Template](partner-onboarding-template.md) | Register a new partner into the program | Once, at onboarding |
| [Partner Progress Template](partner-progress-template.md) | Create the partner's main public progress page | Once, then maintain continuously |
| [Monthly Update Template](monthly-update-template.md) | Record monthly progress, blockers, and next actions | Monthly |
| [Evidence Template](evidence-template.md) | Document capability evidence and reviewer validation | Per milestone / capability gate |
| [Quarterly Review Template](quarterly-review-template.md) | Review readiness movement and next-quarter priorities | Quarterly |

---

## Recommended Operating Flow

```text
Partner Onboarding
       ↓
Create Partner Progress Page
       ↓
Monthly Update
       ↓
Evidence Submission
       ↓
Reviewer Validation
       ↓
Readiness Update
       ↓
Quarterly Review
       ↓
Next Capability Milestone
```

---

## Which Template Should I Use?

### New Partner

Start with:

1. [Partner Onboarding Template](partner-onboarding-template.md)
2. [Partner Progress Template](partner-progress-template.md)

### Existing Partner — Monthly Update

Use:

1. [Monthly Update Template](monthly-update-template.md)
2. update the partner file under `partners/`

### Capability Gate / Assessment

Use:

1. [Evidence Template](evidence-template.md)
2. update readiness status after reviewer validation

### End of Quarter

Use:

1. [Quarterly Review Template](quarterly-review-template.md)
2. review capability gaps and next-quarter priorities

## Standard Status Values

Use these values consistently:

- `Not Started`
- `In Progress`
- `Completed`
- `Validated`
- `Blocked`

---

## Standard Readiness Levels

Use the [Partner Readiness Framework](../framework/partner-readiness.md):

- `Foundation`
- `Developing`
- `Ready`
- `Advanced`

---

## Public Repository Rule

All templates are designed for a public repository. Do not add:

- Huawei confidential information;
- customer confidential information;
- private pricing;
- opportunity values;
- revenue;
- cloud consumption values;
- passwords, tokens, or access keys;
- personal certification IDs;
- exam vouchers;
- internal screenshots;
- contracts or restricted documents.

Use sanitized status-only reporting where required.
